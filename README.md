# 账号簿 v0.1.6

用于个人使用的 Windows 本地 ChatGPT 账号台账。使用 Rust、Tauri 2 和 React/TypeScript。

## 安装与升级

解压 Windows x64 压缩包，双击 **Account Desk.exe**。请把随附的 `WebView2Loader.dll` 与程序放在同一目录。运行需要 Microsoft Edge WebView2 Runtime。

升级时先关闭旧版，再运行新版。默认数据目录为 `%LOCALAPPDATA%\local.accountdesk.vault`，新版会读取原有账号、设置和本机 Codex 连接。若旧版使用了 `--data-dir`，新版也使用同一个路径，例如 `--data-dir "F:\我的账号库"`。

## 台账操作

- 「设置与备份」中的「闲置后自动锁定」可设为「永不」。右上角的手动锁定仍可用。
- 在登录界面勾选「信任此设备，记住主密码」。同一个 Windows 用户在这台电脑重新启动应用时会自动解锁。手动或闲置锁定后可点「使用本机解锁」。在设置中可以撤销信任，恢复加密备份时使用备份主密码。
- 长按账号行约 0.3 秒后上下拖动，也可以聚焦行首手柄后按上下方向键。用「按账号编号」和「自定义顺序」切换视图。先清除筛选，再拖动排序。
- 快速导入按每行一条 `邮箱----密码----2FA` 粘贴，再检查格式并导入。2FA 支持 Base32 密钥和常见的六位、30 秒 TOTP 链接。留空时保留最后四个连字符。
- 在详情中管理邮箱、密码、验证器和备注。编辑时留空会保留已有密码或密钥，对应的清除选项可删除凭据。邮箱改绑可选「未改绑」「已改绑」「原生」。旧版的「未记录」和「待改绑」显示为「未改绑」。「待复核」根据人工核验日期和续费日期生成。

## Codex 连接与额度

1. 在「设置与备份 → Codex CLI」点「自动查找」，或手动选择可信来源的 `codex.exe`。
2. 打开账号详情，在「Codex 连接」点「连接 Codex」，用与台账一致的邮箱完成浏览器登录和授权。默认勾选「用无痕窗口打开授权」，支持作为 Windows 默认浏览器的 Edge、Chrome 和 Firefox。也可复制授权链接，再粘贴到自己打开的无痕窗口。
   等待授权时可以点「取消登录」，或按 Esc 取消本次请求。重新连接过程中取消时会保留原有连接。
3. 授权后会立即读一次额度。之后在解锁时检查已有连接，也可用列表上的「刷新 Codex」或详情中的「刷新」主动查询。在设置里可选择每 15、30 或 60 分钟刷新，定时查询在窗口显示且账号库解锁时运行。选择「仅解锁时刷新」会停止定时查询。
4. 「额度监控」显示 Codex 返回的窗口、剩余百分比和重置倒计时。实际窗口随账号和返回数据而定。鼠标停在额度条上可查看具体重置时间。
5. 有可显示的重置卡数量时，账号详情的 Codex 连接区下方展示金色卡片，列表头像也有金色流光。暂未更新的正数记录会注明为上次记录。
6. 已连接账号用 Codex 返回的信息显示套餐和可用状态。网络或服务错误会显示「暂无法核验」并保留上次额度。手填数据仍可在详情中查看和修改。

[Codex 额度与重置卡字段](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)

## 用量统计

- 侧栏进入「用量统计」，选择「今日」「近 7 天」「近 30 天」或「全部」。近 7 天和近 30 天都包含今天。
- 首次进入时点「接入默认 Codex 日志」，或在「日志设置」里选择其他会话目录。默认路径是 `%USERPROFILE%\.codex\sessions`，配置了本机 `CODEX_HOME` 时使用其 `sessions`。确认目录只对应一个账号时，可以在日志设置里为现有目录指定或修改归属。单个目录曾混用多个账号时请保留未归属。
- 统一按会话日志统计 Token、请求数、估算成本和缓存命中率。点击指标卡切换绘图指标，在折线图、柱状图和点阵图中选一种显示。下方可切换请求日志、账号和模型汇总。
- 「刷新用量」重新扫描已接入的目录。结果覆盖这些目录里仍保存的会话记录。请求数统计含用量记录的模型响应，缓存命中率为缓存读取 Token 占输入 Token 的比例。
- 成本按已知模型的公开 API 标准费率估算，以 USD 显示。页面会标出进入估算的请求数量。目录归属和路径写入加密库，会话用量明细在内存中统计。

[OpenAI API 费率](https://developers.openai.com/api/docs/pricing)

## 价格监控

- 打开「价格监控」后从 PriceAI 的 Price Radar 读取 ChatGPT Plus 报价。首次同步成功后，程序运行时约每 5 分钟检查一次。点「刷新报价」可主动检查，重复检查有频率限制。
- 近 24 小时和近 7 天的峰价、谷价基于已保存快照各自的最低报价。本机从首次同步开始积累记录，图上显示实际覆盖时间。报价来源为 PriceAI，数据延迟或断开时显示上次快照及提示。
- 价位筛选覆盖 Price Radar 的前 5 条报价和单列最低价；未提供库存数的有货报价单独计数。「全部有货报价」为来源提供的商品总览计数。价格缓存保存在当前数据目录，与加密台账分开。

[PriceAI Price Radar 文档](https://priceai.cc/price-radar-api.md)

## 开发与构建

在 Windows 上从仓库根目录运行以下命令。

```powershell
./tools/dev.ps1 -Task Setup
./tools/dev.ps1 -Task Build
```

可执行文件和 `WebView2Loader.dll` 位于 `src-tauri\target\release`。查看 [开发与交接手册](docs/DEVELOPMENT.md) 了解热重载、并行 worktree 和桌面测试。
